# 功能特色

## 核心处理闭环

- 批量扫描、归组、识别和分类。
- 按旧版规则批量移动与重命名，保留发布组、音轨、字幕和洗版变量。
- 生成 STRM、NFO、字幕和图片侧车。
- 完成 TMDb 刮削、AI 翻译、媒体信息格式化和 Emby 入库。
- 入库成功、更新和洗版统一写入任务日志并发送通知。

## 资源与订阅

- 共享池、影巢、频道监听和 MoviePilot 独立作为资源来源。
- 订阅中心统一管理追剧、合集补齐、榜单补齐和演员订阅。
- 云资源搜索保留来源标签和媒体版本信息，可直接提交后台任务。

## 前端与排障

- 资源中心、订阅中心、任务中心和整理记录按用户操作顺序排列。
- 任务中心显示完整后代任务、阶段结果、实时日志和历史日志。
- 整理记录按剧集季度聚合，支持纠错、重组和联动清理。
- 只读智能排查只读取脱敏状态和日志，不会修改数据库、配置或任务。
- 明暗模式、卡片大小、透明度和背景图偏好持久化保存。
