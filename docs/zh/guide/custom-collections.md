# 虚拟库

旧版“自建合集”在新版统一称为“虚拟库”。它把合集、规则筛选或推荐结果作为 Emby 的虚拟媒体库来源。

## 类型

- **规则虚拟库**：实时按分类、标签、评分或其他规则筛选，不依赖刷新后持久化媒体项。
- **TMDb 合集虚拟库**：使用 TMDb 合集成员作为来源。
- **推荐虚拟库**：Pro 功能，可按全局或指定用户生成推荐。

## 访问

虚拟库通过独立反代端口提供访问，默认 `8097`。Emby Web 使用混合库返回，其他客户端按电影库或剧集库返回，这是旧版为避免浏览器电影库报错保留的分流。

普通用户不能配置 Pro 虚拟库。虚拟库的地址、端口、允许转码和用户访问范围均在 Emby 配置页保存。
