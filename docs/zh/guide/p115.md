# 115 网盘

115 是 ETKvNext 的核心存储和播放来源。所有目录使用网盘浏览器选择，避免手动填写容易出错的 CID。

## 授权

- **OpenAPI 登录授权**是主方式：点击登录后在弹出的窗口完成授权，凭据由服务端保存。
- **Cookie 扫码**是辅助方式：可选择不同客户端，减少多设备互踢。
- 两种接口由旧版稳定逻辑自动切换；请求失败会记录实际使用的接口和原因。

## 必要目录

- 待整理目录：资源转存后进入这里。
- 媒体库根目录：生成 STRM 或实体媒体的根路径。
- 未识别目录：无法确认 TMDb 身份的文件暂存位置。
- 图片仓库：留空时使用 `/config/media_images`。

## 整理流程

1. 扫描并按电影、剧集、季度归组。
2. 沿用旧版识别顺序和文件名/目录兜底，保留 TMDb、季集、发布组等上下文。
3. 读取 MediaInfo，应用分类、命名和洗版优先级。
4. 按目标分类批量移动、批量重命名，再生成 STRM 和侧车。
5. 刮削元数据、翻译人物和简介，提交 Emby 扫描并等待 ItemID 校验。

剧集以整季作为任务边界，分集是任务内部处理项，不会在任务中心生成一集一个顶层任务。

## 播放

ETKvNext 保留旧版稳定播放分流：Emby、Jellyfin、ffmpeg、Kodi 等客户端由 ETKN 中转并透传 Range，其他客户端使用 302 直链。虚拟库使用独立反代端口 `8097`。

## 常见配置

- 请求间隔支持 `0.1` 秒步进，推荐 `0.5` 秒。
- 分类、重命名、洗版、映射和词表在核心处理页面独立保存。
- 开启截图后，分集缺少官方剧照时会触发片段截图并写入图片仓库。
