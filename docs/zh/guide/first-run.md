# 首次配置

## 1. 登录授权

首次访问时使用 Emby 管理员账号登录。服务授权页面会保存 Emby 授权凭据，并按旧版流程自动安装或更新 ETK MediaInfo Bridge 插件。插件地址使用 ETKN 的服务地址，不需要另行部署安装器。

## 2. 基础授权

进入“设置中心 -> 服务授权”，依次完成：

- **Emby**：服务器地址和管理员授权。
- **115**：OpenAPI 登录授权为主，Cookie 扫码为辅助方式；双接口会按旧版逻辑自动切换。
- **TMDb**：填写 API Key 和语言偏好。
- **网络代理**：TMDb、GitHub、Telegram、影巢等外部网络请求共用代理配置。

未授权的 115 或外部服务等同于未启用，不需要额外设置模块总开关。

## 3. 配置媒体库

Emby 配置页面中的媒体库、待处理媒体库、片头提取媒体库和媒体库根目录都使用目录/媒体库浏览器选择，不要求手打名称。留空的图片仓库使用 `/config/media_images`。

## 4. 第一次入库

先在 115 页面配置待整理目录、媒体库根目录、分类、重命名和洗版规则，再把一部电影或一季剧放入待整理目录。资源中心转存成功后会自动进入同一套整理流程。
