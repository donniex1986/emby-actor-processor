# 任务中心

任务中心是所有后台工作的统一入口。

## 顶层任务

顶层任务按资源、电影或剧名/季度显示。分集只作为根任务内部的处理项和日志，不会把一季拆成十几个顶层任务。

## 任务链

常见链路为：

`资源获取 -> 扫描 -> 识别 -> 整理 -> 刮削 -> 翻译 -> 媒体分析 -> 入库 -> Emby 校验`

某个阶段失败会阻断依赖阶段，并在同一个任务中显示中文原因和建议。STRM 生成不代表任务完成，必须等后续刮削、翻译、入库和校验结束。

## 日志

- 运行中的任务：点击查看实时日志。
- 已完成任务：点击查看完整历史日志。
- 下载或复制日志：只包含当前根任务及已登记的后代任务，不会和其他任务串门。
- “智能排查”按钮只有在 AI 配置中开启后才显示，AI 只有只读权限。

## 单任务 CRON

工具箱任务保留分类标签，每个支持定时的任务可以独立设置 CRON。保存后下一次调度生效，不需要保存整页配置。
