# Web 控制台

入口：`http://服务器IP:5257`

## 主菜单

- **资源中心**：共享池、影巢、频道监听、MoviePilot 和云资源搜索。
- **订阅中心**：智能追剧、合集补齐、榜单补齐、演员订阅和统一订阅进度。
- **任务中心**：根任务、后代任务、实时日志、历史日志和只读智能排查。
- **整理记录**：历史整理、分季聚合、纠错、重组和联动删除结果。
- **设置中心**：基础设置、Emby、115、元数据、AI、TG、代理和任务配置。

## 任务日志

资源获取、扫描、整理、刮削、翻译、入库和 Emby 校验属于同一条任务链。正在处理的任务查看实时日志，已完成任务查看完整历史日志；每条日志只属于当前根任务及已登记的后代任务。

任务标题优先显示片名或剧名，数字诊断编号只作为辅助信息。失败时先看中文阶段、失败原因和建议，再展开诊断详情。

## 偏好设置

用户偏好会自动保存，包括明暗模式、卡片大小、玻璃透明度、背景图和模糊度。模态框会继承全局透明度，打开时页面背景不会位移。
