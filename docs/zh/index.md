# ETKvNext 文档

ETKvNext 是 ETK 的新架构版本。它保留旧版经过长期验证的整理、刮削、入库、播放和订阅逻辑，同时把配置、任务、日志和前端重新组织，让日常使用更容易排查和维护。

如果你是第一次使用，建议按下面顺序阅读：

1. [快速开始](/zh/guide/quick-start)：启动容器并完成登录。
2. [首次配置](/zh/guide/first-run)：完成 Emby、115、TMDb 和代理授权。
3. [Web 控制台](/zh/guide/web-ui)：了解资源中心、订阅中心、任务中心和整理记录。
4. [115 网盘](/zh/guide/p115)：配置目录、整理、STRM 和播放。
5. [故障排查](/zh/faq/troubleshooting)：查看任务日志并定位失败阶段。

## 核心能力

- 自动整理 115 网盘中的电影、剧集和季包。
- 生成 STRM，并完成 TMDb 刮削、AI 翻译、媒体信息格式化和 Emby 入库。
- 从共享池、影巢、频道监听和 MoviePilot 获取资源。
- 通过订阅中心统一管理追剧、合集补齐、榜单补齐和演员订阅。
- 按清晰度、编码、音轨、字幕、纯净版等偏好执行洗版。
- 提供播放反代、虚拟库、Telegram 通知和只读智能排查。

## 菜单顺序

- **资源中心**：共享池、影巢、频道监听、MoviePilot 和云资源搜索。
- **订阅中心**：集中管理所有可发起订阅的需求和进度。
- **任务中心**：查看根任务、完整任务链、实时日志和历史日志。
- **整理记录**：按剧集季度聚合查看整理历史、纠错和重组。
- **设置中心**：模块独立保存配置，避免跨页面反复保存。

## 重要说明

ETKvNext 与旧版 ETK 不要同时处理同一批媒体。旧版正式数据迁移使用独立 Windows 工具；新版启动迁移只负责创建或升级数据库结构，不会自动搬运测试数据。
